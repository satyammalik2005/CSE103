# Markdown Syntax Guide

This file demonstrates the Markdown features used in the project README.

## Headings

Use one to six `#` characters to create headings. The number sets the heading level.

# Heading 1
## Heading 2
### Heading 3

## Text Formatting

- **Bold text** uses two asterisks on each side.
- *Italic text* uses one asterisk on each side.
- ~~Strikethrough text~~ uses two tildes on each side.

## Lists

Unordered list:

- Item A
- Item B
  - Nested item B1 (indent with two spaces)

Ordered list:

1. First step
2. Second step

## Code

Inline code: `print("Hello")`

Fenced code blocks can include a language name for syntax highlighting:

```python
def greet(name):
    return f"Hello, {name}!"
```
